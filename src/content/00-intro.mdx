## 什么是强化学习？

<strong>强化学习（Reinforcement Learning, RL）</strong>研究的问题是：一个智能体如何通过与环境反复互动，学会做出好的决策。

先忘掉定义，想象你在训练一只小狗：你不会给它看一本《Sit 训练教程》，你只会在它做对时给零食、做错时不给。几次之后，它自己"悟"出了坐下的动作。强化学习就是把这件事变成数学：**没有人告诉智能体正确答案是什么，它只从环境的奖励中摸索**。

把这个过程拆开，只剩三个关键词：

- **状态（State）**：世界此刻的样子——小狗看到你举起了零食；
- **动作（Action）**：智能体可以选择的行为——坐下、打滚、或者干看着；
- **奖励（Reward）**：环境对动作的即时评价——零食（+1）或失望（0）。

## 它和你熟悉的监督学习有什么不同？

| | 监督学习 | 强化学习 |
| --- | --- | --- |
| 反馈信号 | 正确答案（标签） | 只有奖励，且可能是延迟的 |
| 数据从哪来 | 事先收集好的数据集 | 智能体自己的交互经验 |
| 目标 | 复制正确答案 | 最大化长期累计奖励 |

第三行是关键：强化学习要优化的不是"这一步对不对"，而是**整条轨迹的长期收益**——为了几步之后的零食，小狗愿意先忍耐一会儿。

## 奖励、回报，以及那个无处不在的 γ

强化学习建立在一条朴素的信念上（**奖励假设 / Reward Hypothesis**）：*一切目标都可以表述为最大化期望累计奖励*。

"累计奖励"有个正式名字——**回报（Return）**，记作 $G_t$，表示从时刻 $t$ 之后能拿到的奖励总和。通常近期的奖励比远期的更值钱，于是引入**折扣因子 γ（discount factor）**：

$$G_t \;=\; R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots \;=\; \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$

γ 的取值很能体现"性格"：

- $\gamma = 0$：目光短浅，只看眼前的这一步奖励；
- $\gamma = 0.9$：务实，大约关心未来 10 步以内；
- $\gamma \to 1$：长远谋划，愿意为了大目标忍很久（但也可能为了遥远的幻觉饿死在当下）。

在第 2 章（马尔可夫决策过程）里，γ 会成为你亲手转动的第一个旋钮。

## 术语速查表

| 中文 | 英文 | 一句话解释 |
| --- | --- | --- |
| 智能体 | Agent | 做决策、在学习的那个"你" |
| 环境 | Environment | 智能体之外的一切，负责回应动作 |
| 状态 | State, $s$ | 世界此刻的样子 |
| 动作 | Action, $a$ | 智能体可以做的选择 |
| 奖励 | Reward, $r$ | 环境对一步动作的即时评价 |
| 回报 | Return, $G_t$ | 从现在起累计的未来奖励（打折后） |
| 折扣因子 | Discount factor, $\gamma$ | 未来奖励的"汇率"，$0 \le \gamma \le 1$ |
| 策略 | Policy, $\pi$ | 智能体的决策规则：状态 → 动作 |
| 轨迹 | Trajectory, $\tau$ | 一条 $s, a, r, s, a, r \ldots$ 序列 |
| 回合 | Episode | 从开始到结束的一段完整交互 |

## 小结

- 强化学习 = 智能体通过「状态 → 动作 → 奖励」循环的试错，学会最大化长期回报；
- 它与监督学习的本质区别：反馈是**评价性**的（只有奖励）而非**指导性**的（有正确答案），且数据由交互自产；
- 回报 $G_t$ 和折扣因子 γ 是贯穿全课程的两个基础概念。
